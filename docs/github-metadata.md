Authoring-source package for portable thinking skills and Claude Code compatible command projections.

`thinkcraft` is a standalone repository for canonical thinking-skill source files, normalized metadata, documented projections, and validation. It is not a runtime or installer.

## Release-page positioning

Use release text that follows this order:

1. State that `thinkcraft` is an authoring-source repository.
2. State that it defines canonical skills, metadata, and projections.
3. Mention Claude Code compatible command usage only after the source model is clear.
4. Mark `v0.1.0` as a public preview.
5. Avoid installer, runtime, registry, or package-manager language.
