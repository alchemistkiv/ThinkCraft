# thinkcraft v0.1.0-preview

`v0.1.0` is the first public preview of `thinkcraft` as a standalone authoring-source repository.

## What this release is

- A clean standalone repo for canonical thinking-skill source files
- A normalized metadata package centered on `manifest.yaml`
- A documented projection model for bundled skills and Claude Code compatible disk commands
- A preview release meant for review, experimentation, and package-shape validation

## What is included

- Six canonical thinking skills in `skills/`
- Command-template source files in `templates/commands/`
- Projection mapping and architecture docs in `docs/`, `catalog/`, and `adapters/`
- An example Claude Code compatible project projection in `examples/project/`
- A lightweight validator in `tests/validate_package.py`

## What this release is not

- Not a runtime distribution
- Not an installer
- Not a registry integration
- Not a package-manager artifact
- Not a guarantee of stable downstream projection formats yet

## Validation

The intended validation command for this preview is:

```bash
python tests/validate_package.py
```

The validator checks source-package integrity rather than runtime behavior.

## Preview note

This release establishes the repository position and the source model first. Usage guidance is intentionally secondary. Claude Code compatible command files are represented here as a projection target and example delivery format, not as the source of truth.

## Recommended release-page blurb

`thinkcraft` is a standalone authoring-source package for structured thinking skills, normalized metadata, and documented projections. `v0.1.0` is an early public preview focused on source integrity, portability, and Claude Code compatible command projection.
