# design

Use this command when the broad direction is chosen and the structure now needs to become actionable.

## What to do

- State the design target and success conditions.
- Define the major components, boundaries, or stages.
- Show the flow of data, decisions, or interaction.
- Make open decisions explicit.
- Explain why this structure is preferable to the nearest alternative.

## Output

- Design target
- Proposed structure
- Flow description
- Open decisions with comparison basis
- Recommended next implementation or review step
